\subsection{Radial Distortion Removal}\label{subsec:radialdistortion}

Radial distortion is a type of unavoidable distortion that bends straight lines.

In the course, we saw that radial distortion can be modeled as follows:
\begin{equation}\label{eq:radialdistortion}
\begin{cases}
    x'&=p_x+(x-p_x)(1+k_1 r^2+k_2 r^4)\\
    y'&=p_y+(y-p_y)(1+k_1 r^2+k_2 r^4)
\end{cases}
\end{equation}
Where the point $(x,y)$ lands in $(x',y')$ in the distorted image, with
$r^2=\left\| (x,y)-(p_x,p_y) \right\|_2^2=(x-p_x)^2+(y-p_y)^2$.
This means that all points $(x,y)$ at an equal distance $d$ from the principal point $p=(p_x,p_y)$ get distorted the
same amount.
Furthermore, only knowing $p$ and $k_1,k_2$ enables one to invert any distortion by inverting
equation~\eqref{eq:radialdistortion}.

IPOL~\citep{lensdistortioncorrection} implemented an algorithm to estimate and remove radial distortion on input images.
Let us roughly describe how the algorithm works.

First of all, edges are detected using Canny edge detection.
This algorithm works by computing the gradient at every pixel and then selecting the pixels whose gradients are local
maxima \textit{along the direction of the gradient} (in that way, the lines we get can only be at most one pixel thick).
Out of these, the ones with a gradient norm higher than some threshold are considered edges.
If the gradient norm is greater than some other low threshold, the points get investigated more before being discarded:
if they are next to a point that is classified as an edge, they also get classified as edges.

An improved version of the Hough transform is used to group the edge points into lines.
The Hough transform works by mapping points $(x,y)$ to functions in the 2D space $(\theta,\rho)$ where each point
corresponds exactly one line, where $\theta$ is the angle between the normal to the line and the origin and $\rho$ is
the distance of the line to the origin.
The set of lines that can go through the point $(x,y)$ can be computed by varying the angle of the normal to the line
$\theta$ (and $\rho=x\cos\theta + y\sin\theta$).
In practice, we consider a limited number of possible values of $\theta$.
If multiple points are on a line, then their corresponding curves in the $(\theta,\rho)$ space will intersect at the
point that corresponds to the line they lie in.
The points in the Hough space that have a large number of functions that go through them are most likely lines in the
input image (this process is called voting and works by associating to each point in the discretized Hough space the
number of curves that go through them).\footnote{I took the time to properly explain the Hough transform because as a
CS major, I never encountered it before.}

The issue with the Hough transform is that it can only detect straight lines, but lines get distorted by radial
distortion (note that the straight lines don't get bent much close to the distortion center).
The idea is to consider a 3-dimensional Hough space $(\theta,\rho,k)$ where $k$ is a single parameter that models the
radial distortion applied to the input image (in particular the center of distortion would be at the center of the
image).

The idea is that, for every value of $k$ considered, we construct the undistorted image and perform the Hough transform
on these \("\)corrected\("\) images.
Then, the value of $k$ that is used is the one that produces the better lines.
The way this is done is by attributing a score $v_k$ for every value of $k$:
\[v_k=\sum_{j=1}^{n}
\sum_{p\in\text{Edge}:d(line_j,C_k(p))<1} \frac{1}{1+d(line_j,C_k(p))}\]
The above equation states that for every line $1\leq j\leq n$ that the Hough transform has found in the corrected picture
(with radial distortion parameter $k$), we consider the points $p\in\text{Edge}$ that are close enough to
the $j$th line and add a term that penalizes $k$ if the points land far from the line.

Intuitively, this procedure is equivalent to testing out a large number of simple lens models and keeping the one that
gives us the straightest lines.
Obviously, the model here is too simple for it to find every line: only some fraction of the lines will be successfully
retrieved correctly but this gives us enough to start optimizing.

Once a first set of lines and a first estimation of the lens model has been achieved begins the iterative optimization
part.
The lens distortion model is a tuple $\mathbf{k}=(k_1,k_2,p_x,p_y)$, exactly as in equation~\eqref{eq:radialdistortion}.
The previous step gave us a set of lines $\{line_j\}_j$.

\begin{equation}\label{eq:energydistortion}
    E(\mathbf{k})=\sum_{line_j}\sum_{p\in line_j}d(C_{\mathbf{k}}(p), line_j)^2
\end{equation}

By minimizing $E$, one can find a new (hopefully better) estimation of the lens distortion model which makes new lines
appear.
Using a regular 2D Hough transform, one can find straight lines in the corrected image (the one induced by the
value of $\mathbf{k}$ that was just found by the optimization procedure).
If this Hough transform gives new lines, we can perform a new pass of the optimization procedure described just above
and keep repeating until no new lines are found.
Once no new lines are found, the algorithm stops and the final lens distortion model is the final value of
$\mathbf{k}$ (\textit{QR.1}).

We have seen that radial distortion can be modeled with equation~\eqref{eq:radialdistortion}.
This model of radial distortion is known as the \textit{polynomial} model.
There exists another way of modeling distortion (which does not have any physical interpretation) known as the
division model:
\begin{equation}\label{eq:radialdistortiondivision}
    \begin{cases}
    x'&=p_x+(x-p_x)\frac{1}{1+k_1 r^2+k_2 r^4}\\
    y'&=p_y+(y-p_y)\frac{1}{1+k_1 r^2+k_2 r^4}
\end{cases}
\end{equation}

Figures~\ref{fig:outputpolynomial} and~\ref{fig:outputdivision} show the result of~\citep{lensdistortioncorrection} on
the same image but using respectively the polynomial and the division models.

Immediately, we observe that the division model gives a better result on this specific image: the handrail is still
bent in the first corrected image.
Because of the better model, the Hough transform actually finds more lines in the division corrected image (70) than in
the polynomial corrected image (61).
It seems that doing radial distortion removal with the polynomial model tends to actually underestimate the strength
of the distortion.
From our testing, we observe that this happens consistently whevener the strength of the distortion is high.
Indeed, we can see that the lines present at the edge of the uncorrected image (which are thus strongly distorted) are
more likely to be correctly identified when using the division model (\textit{QR.2}).

In various output figures, we noticed blurry regions.
The blurry regions come from the fact that the edges of the picture are stretched.
The further the pixel is from the center of distortion, the largest the stretching required to recover the straight
lines and thus the more blur.
This explains why the part of the image close to the center of distortion remains unblurred.

Note that this effect is exagerrated in pictures [A] and [B] because the edges of the image were already blurred to
begin with.

In general, in the right conditions, the results seem to be reliable.
That is, if the image contains enough feature points and (distorted) straight lines, the algorithm will most likely
correct the radial distortion (at least relatively good results if used with the division model).
This means that it is not possible (will produce at least using this specific technique) to undistort an image that was
taken of a scene that does not have any straight lines.
One can easily demonstrate this fact by applying the algorithm to an image of, say, a ballpit.
Figure~\ref{fig:ballpitdistortion} shows that the algorithm fails in such a situation (\textit{QR.5}).

Finally, one might ask himself what is the influence of the signs of $k_1$ and $k_2$ on the type of distortion in
the distorted image.
To answer this question, we will study analytically what happens to a horizontal line when distorted.

Let us assume that $p=(0,0)$ is the center of the image plane to simplify computations and consider the line $y=1$.
We are interested in what happens to the $y$ coordinate of a point $(x,1)$ on the line.
By equation~\eqref{eq:radialdistortion}, we have:

\[y'=1+k_1 (x^2+1)+k_2 (x^2+1)^2\]

Taking the derivative, we obtain
\[\frac{dy'}{dx}=2k_1 x+4k_2 x(x^2+1)\]

If $k_1,k_2<0$, we find that $y'$ is increasing for $x<0$ and decreasing for $x>0$.
Hence, we get barrel distortion.
If $k_1,k_2>0$, we find that $y'$ is decreasing for $x<0$ and increasing for $x<0$.
This is pincushion distortion.

Note that with this model, if $k_1$ is of a different sign than $k_2$, we can have that horizontal lines get distorted
in ways that are neither \enquote*{barrel} nor \enquote*{pincushion} (one can picture some arbitrary fourth-degree
polynomial, \textit{QR.6}).
